# CSS Learning Journey

A complete beginner-friendly CSS learning journey covering concepts,
theory, practical problem solving, mini projects, a main project,
responsive layouts, UI components, and documentation.

---

## 🎯 Goal

Build a strong CSS foundation after HTML before moving to JavaScript,
React.js, and modern front-end development.

The learning approach is:

```text
Learn
  ↓
Understand
  ↓
Practice
  ↓
Build
  ↓
Review
  ↓
Debug
  ↓
Document
```

# 🧠 9. Learning Decisions & Improvements

The roadmap was reviewed during learning instead of blindly following a
fixed list.

### Changes Made

* Organized CSS concepts into a structured learning sequence.
* Separated concepts, theory practice, practical problems, mini
  projects, and the main project.
* Used **20 theory questions** to cover the major CSS concepts.
* Added **20 practical problems** for hands-on CSS practice.
* Combined related CSS properties into focused practice files.
* Included Flexbox and Grid as dedicated layout topics.
* Included responsive design and media queries as dedicated topics.
* Added pseudo-classes and pseudo-elements as separate practice areas.
* Added CSS variables and modern CSS functions.
* Added shadows, gradients, and object-fit practice.
* Added common UI component practice such as navigation bars, cards,
  login forms, and dashboards.
* Kept four mini projects to avoid unnecessary repetition.
* Added a complete responsive portfolio website as the main project.
* Kept assets organized separately from concepts, practice, and
  projects.

This keeps the learning process focused and manageable.
