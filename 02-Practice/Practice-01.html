CSS Theory & Practice

Q1. What is CSS? Why is CSS used in web development? Explain the different ways to add CSS to an HTML document.

CSS (Cascading Style Sheets) is a stylesheet language used to design and format the appearance of HTML documents.

Why CSS is used: It separates document structure from styling, enables reusable styles across web pages, improves page loading speed, and makes pages responsive across devices.

Ways to add CSS:

  • Inline CSS: Added directly in an HTML tag using the style attribute.
  • Internal CSS: Placed inside a <style> tag within the <head> section.
  • External CSS: Linked from a separate file using <link rel="stylesheet" href="style.css">.
Q2. What are CSS selectors? Explain Element, Class, ID, Universal, and Grouping selectors with examples.

CSS selectors are patterns used to select and target the HTML elements you want to style.

  • Element: Selects tags by element name (e.g., p { color: blue; }).
  • Class (.): Selects elements by class attribute (e.g., .btn { padding: 8px; }).
  • ID (#): Selects a single unique element by ID (e.g., #header { background: gray; }).
  • Universal (*): Selects all elements on the page (e.g., * { margin: 0; }).
  • Grouping (,): Applies the same rules to multiple selectors (e.g., h1, h2 { color: black; }).
Q3. What is the difference between descendant, child, adjacent sibling, and general sibling selectors? Give an example of each.
  • Descendant (space): Matches all descendants at any nesting level (e.g., div p).
  • Child (>): Matches only direct children (e.g., ul > li).
  • Adjacent Sibling (+): Matches an element directly following another element (e.g., h2 + p).
  • General Sibling (~): Matches all sibling elements following another element (e.g., h2 ~ p).
Q4. What are attribute selectors in CSS? Explain how [type="text"] works with an example.

Attribute selectors target elements based on an attribute name or value.

[type="text"] targets only input elements that have type="text".

input[type="text"] {
  border: 1px solid #ccc;
  padding: 6px;
}
Q5. Explain the different ways to represent colors in CSS. What are HEX, RGB/RGBA, and HSL/HSLA?
  • Named Colors: Standard keywords like red or blue.
  • HEX: Hexadecimal color codes (e.g., #ff0000).
  • RGB / RGBA: Red, Green, Blue (0-255) with optional Alpha opacity 0-1 (e.g., rgba(255, 0, 0, 0.5)).
  • HSL / HSLA: Hue (0-360), Saturation (0-100%), Lightness (0-100%), and Alpha opacity (e.g., hsl(0, 100%, 50%)).
Q6. Explain commonly used CSS properties for styling text and fonts with examples.
p {
  font-family: Arial, sans-serif; /* Typeface */
  font-size: 16px;                /* Text size */
  font-weight: bold;              /* Text thickness */
  text-align: center;             /* Alignment: left, right, center */
  text-decoration: underline;     /* Underline or none */
  line-height: 1.5;               /* Spacing between lines */
}
Q7. What are CSS units? Explain the difference between px, %, em, rem, vw, and vh.
  • px: Absolute pixels (fixed size).
  • %: Relative to the parent element's size.
  • em: Relative to the font-size of the element itself.
  • rem: Relative to the root <html> element's font-size.
  • vw / vh: 1% of the viewport width / height.
Q8. Explain the CSS box model (content, padding, border, margin) and box-sizing.

Every HTML element is treated as a rectangular box consisting of:

  1. Content: Text, images, or child elements.
  2. Padding: Space inside the border, surrounding content.
  3. Border: Line wrapped around padding and content.
  4. Margin: Space outside the border separating neighboring elements.

box-sizing: content-box adds padding/border to width; border-box includes padding/border inside the specified width.

Q9. Explain the difference between block, inline, inline-block, display: none, visibility: hidden, and opacity: 0.
  • block: Starts on a new line and takes full width. Respects width and height.
  • inline: Stays inline with text. Ignores width and height.
  • inline-block: Stays inline with text, but respects width and height.
  • display: none: Completely removes element from document layout.
  • visibility: hidden: Hides element visually, but preserves its empty space.
  • opacity: 0: Makes element transparent; space is preserved and it remains clickable.
Q10. Explain static, relative, absolute, fixed, and sticky positioning with use cases.
  • static: Default flow. Offsets (top/left) do not apply.
  • relative: Moved relative to its normal position without affecting others.
  • absolute: Positioned relative to its closest positioned ancestor. (Use case: popup close buttons).
  • fixed: Positioned relative to the browser viewport; stays on screen while scrolling. (Use case: navbar).
  • sticky: Toggles between relative and fixed based on scroll position. (Use case: sticky table headers).
Q11. What is Flexbox? Explain flex-direction, justify-content, align-items, flex-wrap, gap, and align-self.

Flexbox is a 1-dimensional layout model for arranging items along a row or column.

  • flex-direction: Sets the layout direction (row, column).
  • justify-content: Aligns items along the main axis (flex-start, center, space-between).
  • align-items: Aligns items along the cross axis (stretch, center).
  • flex-wrap: Controls whether items wrap onto new lines (nowrap, wrap).
  • gap: Spacing between flex items.
  • align-self: Overrides cross-axis alignment for an individual child item.
Q12. What is CSS Grid? Explain grid-template-columns, grid-template-rows, gap, grid-column, grid-row, repeat(), and fr.

CSS Grid is a 2-dimensional layout system that handles rows and columns simultaneously.

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 equal columns */
  grid-template-rows: auto;
  gap: 15px; /* Gutter between cells */
}

.item {
  grid-column: 1 / 3; /* Spans across 2 columns */
  grid-row: span 2;    /* Spans across 2 rows */
}
Q13. What is responsive web design? Explain flexible layouts, responsive units, responsive images, and breakpoints.

Responsive design makes web pages adapt cleanly to any screen size.

  • Flexible Layouts: Using Flexbox or Grid instead of fixed pixel widths.
  • Responsive Units: Using %, rem, vw, and vh.
  • Responsive Images: Using img { max-width: 100%; height: auto; } to prevent overflow.
  • Breakpoints: Screen width points where layout changes using media queries.
Q14. What are CSS media queries? Explain how @media is used to create responsive layouts.

Media queries apply styles conditionally based on device width or screen type.

/* Default for mobile */
.box { width: 100%; }

/* Tablet and desktop screens */
@media (min-width: 768px) {
  .box { width: 50%; }
}
Q15. What is the difference between a pseudo-class and a pseudo-element? Explain :hover, :focus, :checked, :nth-child(), ::before, and ::after.
  • Pseudo-class (:): Styles an element in a specific state.
    • :hover (mouse hover), :focus (input selected), :checked (checkbox checked), :nth-child(n) (targets specific index).
  • Pseudo-element (::): Inserts and styles virtual elements not in HTML.
    • ::before (inserts content before element) and ::after (inserts content after element). Requires content: "";.
Q16. What is CSS specificity? Explain cascade, inheritance, source order, and !important.

Specificity determines which rule wins when multiple rules target the same element:

Inline style > ID selector > Class/Attribute selector > Element selector.

  • Cascade: Combines specificity, importance, and source order to choose winning styles.
  • Inheritance: Child elements inherit properties like font and color from parents.
  • Source Order: The last rule in the stylesheet wins if specificity is equal.
  • !important: Overrides normal specificity rules.
Q17. Explain the difference between CSS transitions, transforms, and animations with examples.
  • Transforms: Modifies shape, position, or size (e.g., transform: scale(1.1) rotate(10deg);).
  • Transitions: Smoothly animates property changes between two states (e.g., transition: all 0.3s ease;).
  • Animations: Uses @keyframes to create automatic, multi-step animations without user action.
Q18. What are CSS variables (custom properties)? Explain var(), calc(), min(), max(), and clamp().

CSS variables store reusable values using --name and var(--name).

:root {
  --main-color: #007bff;
}

.box {
  background-color: var(--main-color);
  width: calc(100% - 40px);         /* Dynamic math */
  height: min(300px, 50vh);         /* Picks smaller value */
  padding: max(10px, 2vw);          /* Picks larger value */
  font-size: clamp(14px, 2vw, 22px);/* Keeps value between min and max */
}
Q19. Explain box-shadow, text-shadow, linear-gradient(), radial-gradient(), and object-fit (contain vs cover).
  • box-shadow: Adds shadow around an element box (box-shadow: 2px 2px 5px #aaa;).
  • text-shadow: Adds shadow to text (text-shadow: 1px 1px 2px #000;).
  • linear-gradient(): Color transition in a straight direction.
  • radial-gradient(): Color transition radiating from a center point.
  • object-fit:
    • contain: Keeps aspect ratio, shows full image (may show empty space).
    • cover: Keeps aspect ratio, fills the entire box (crops edges if needed).
Q20. How would you use CSS concepts such as Flexbox, Grid, positioning, and media queries to build common UI components?
  • Navbar: Use Flexbox (display: flex; justify-content: space-between;) and position: sticky; top: 0;.
  • Card Grid: Use CSS Grid (grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));).
  • Login Form: Center horizontally and vertically using Flexbox on parent container.
  • Sidebar: Two-column Grid (200px 1fr) that switches to full width on mobile via media queries.
  • Footer: Flexbox column container with margin-top: auto; to pin the footer to the bottom.
